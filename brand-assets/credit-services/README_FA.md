# سرویس‌های اعتباری — وضعیت گردآوری لوگو

فایل `credit-services-research.json` فهرست ۱۲ سرویس اعتباری و وضعیت راستی‌آزمایی دامنه/لوگوی آن‌ها را نگه می‌دارد.

**مهم:** این فهرست کاتالوگ پژوهشی است، نه مجموعه لوگوهای آماده. در این مرحله هیچ لوگوی ساختگی به‌جای لوگوی رسمی قرار نگرفته است. برای دیجی‌شهر مسیر SVG رسمی پیدا شده اما دریافت فایل هنوز کامل نشده؛ برای چند برند دیگر نیز منبع رسمی لوگو هنوز باید استخراج شود.

وضعیت‌ها:
- `verified_official`: دامنه از وب‌سایت یا پروفایل رسمی معرفی شده است.
- `official_social_profile_found_domain_needs_confirmation`: پروفایل اجتماعی رسمی پیدا شده اما دامنه وب نیازمند تأیید است.
- `needs_official_source`: هنوز منبع رسمی کافی برای دامنه/لوگو پیدا نشده است.
- `pending_download`: لوگوی رسمی هنوز دریافت و کنترل کیفیت نشده است.
- `source_identified_not_downloaded`: مسیر لوگو شناسایی شده اما فایل هنوز ذخیره نشده است.

فایل JSON را مرجع وضعیت این مرحله در نظر بگیرید.
